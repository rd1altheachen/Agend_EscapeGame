# 前端視覺設計

先理解目標使用者、頁面主要任務與品牌或產品限制，再選擇能表達內容的視覺方向。避免無根據地套用固定配色、版型或裝飾。

## 設計判斷
- 讓排版、色彩、字體、結構和動態服務於內容；選一個清楚的視覺焦點，其餘元素保持易讀。
- 按 brief 決定所需規劃深度；不強制固定色票數量、wireframe 形式或多階段自評。
- 保持手機可用、鍵盤焦點可見並尊重 reduced-motion。控制項使用明確動作文字；錯誤訊息說明發生什麼及可採取的修正。
- 檢查成品是否符合 brief、品牌要求與主要使用流程；回報尚未驗證的裝置或狀態。

投影片製作按 fleet 現行 PPTX／視覺 owner 路由；此技能聚焦網頁 UI。
