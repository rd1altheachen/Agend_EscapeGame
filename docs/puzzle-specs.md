# 謎題互動規格

## 房間1 東牆

### 物件：星座儀

**首次點擊：** 顯示文字對話框「一個古老的星座儀，球面上刻著星座圖案…似乎可以轉動。」

**再次點擊：** 進入星座儀特寫畫面（從東牆場景圖裁切星座儀區域放大）

**特寫互動：**
- 球面有 3 個位置，每個位置顯示一個星座符號
- 每個位置有上下箭頭，循環切換 6 個選項：紅獅子 → 藍獅子 → 藍水瓶 → 金水瓶 → 金天秤 → 紅天秤
- 初始狀態：三個位置都是「紅獅子」
- 底部有「返回」按鈕

**判定邏輯：**
| 條件 | 反應 |
|------|------|
| 正確答案（位置1=紅獅子、位置2=藍水瓶、位置3=金天秤）且兩個線索都有（星座對照表 + 音樂盒顏色順序） | 成功，獲得魔法砝碼 + ⭐第4顆星星 |
| 正確答案但缺任一線索 | 文字框：「好像還缺什麼東西」 |
| 答案錯誤 | 無反應 |

**所需線索：**
- 星座對照表（謎題 1-1 獲得）：顏色↔星座對應
- 音樂盒顏色順序（謎題 2-1）：紅→藍→金

### 物件：魔法門

**點擊：** 進入鑰匙孔特寫畫面（從東牆場景圖裁切鑰匙孔區域放大）

**特寫互動：**
- 三個菱形鑰匙孔各覆蓋一個菱形 HitBox
- 底部有「返回」按鈕

**點擊鑰匙孔判定邏輯：**
| 條件 | 反應 |
|------|------|
| 背包沒有水晶鑰匙 | 文字框：「沒有鑰匙」 |
| 有鑰匙，缺少地毯線索或咒語線索 | 文字框：「好像還缺什麼東西」 |
| 有鑰匙＋有線索，插錯孔（不是中間） | 無反應 |
| 有鑰匙＋有線索，插對（中間孔） | 觸發鑰匙動畫 |

**鑰匙動畫（約1.5秒）：**
1. 鑰匙從背包飛入中間鑰匙孔（0.5s）
2. 鑰匙孔發出金色光芒（0.5s）
3. 整扇門發光 → 場景淡出切換到房間2（0.5s）

**所需線索：**
- 水晶鑰匙（謎題 1-2 獲得）
- 地毯線索（掀開地毯角落）：鑰匙插中間孔
- 咒語線索（點擊正確的書）：開門咒 Aperio

---

### 咒語線索取得方式

- 玩家透過魔法鏡（謎題 1-1）找到正確的書 → 點擊該書
- 彈窗顯示書的內頁圖片（book-page-aperio.png），上面寫著「開門咒：Aperio」
- 關閉彈窗，書不進背包，系統背景標記 `hasSpellClue = true`
- 玩家需要記住咒語（或回來再看一次）

## UI 共通規格

### 文字對話框
- 半透明黑底（rgba(0,0,0,0.7)）白字
- 出現在場景底部，不遮擋物件
- padding: 12px
- 點擊任意處關閉

### 方向鍵（牆面切換）
- 圓形透明 HitBox，直徑約場景寬度 12%
- 位置：場景圖左下/右下，對準地板上的方向鍵圖案
- 平時完全透明不可見
- 按下時：白色圓形光暈（border: 2px solid rgba(255,255,255,0.8) + box-shadow: 0 0 12px rgba(255,255,255,0.6)），持續 0.3 秒後淡出

### HitBox 通用規則
- 平時完全不可見（無 border、無 box-shadow、無背景色）
- 不顯示 hover 效果
- 只靠點擊回饋讓玩家發現可互動
